# Tabela de Substituições Vocabulares em PT-BR (Sistema de Tiers)

Esta tabela organiza as palavras e locuções problemáticas em **três Tiers de severidade**, fornecendo alternativas concretas, diretas e naturais do Português do Brasil.

---

## 🎯 Como Funcionam os Tiers

- **Tier 1A (Marcadores de IA):** Expressões que ocorrem com frequência desproporcional em modelos de linguagem. Devem ser substituídas em quase 100% dos casos.
- **Tier 1B (Clareza e Anti-Burocratês):** Expressões prolixas ou pomposas que prejudicam a leitura mesmo quando escritas por humanos. Substituição melhora o texto imediatamente.
- **Tier 2 (Suspeitos em Cacho):** Palavras aceitáveis isoladamente, mas que em grupos de duas ou mais no mesmo parágrafo indicam padrão de IA.
- **Tier 3 (Densidade):** Advérbios e palavras comuns que só incomodam quando usados em excesso (mais de 3% do texto total).

## 1. Tier 1A: Marcadores Frequenciais de IA (Substituição Prioritária)

| Expressão a Evitar | Substituição Recomendada | Contexto de Uso / Observação |
|---|---|---|
| **mergulhar em / nos aprofundar** | examinar, analisar, ver de perto, explorar | Tradução direta de *delve into*. |
| **tapeçaria (metafórico)** | complexidade, conjunto, panorama, dinâmica | Tradução de *tapestry*. Quase nunca cabe em prosa informativa. |
| **cenário / ecossistema (genérico)** | mercado, setor, área, ambiente, contexto | Use apenas se estiver falando de biologia real. |
| **reino / esfera (abstrato)** | campo, área, setor, domínio | Evite metáforas feudais para falar de negócios ou código. |
| **orquestrar / catalisar** | coordenar, organizar, iniciar, liderar | Menos afetação teatral. |
| **alavancar** | usar, impulsionar, aproveitar, potencializar | Não use como única opção para qualquer verbo de ação. |
| **farol (metafórico)** | referência, exemplo, modelo | Nomeie quem ou o que é a referência real. |
| **testemunho de (testament to)** | prova, demonstra, mostra, comprova | Ex.: *"Isso prova a solidez da arquitetura."* |
| **divisor de águas / watershed moment** | mudança de rumo, marco importante | Diga o que mudou concretamente. |
| **aninhado (nestled)** | localizado em, situado em, fica em | IA adora *"aninhado no coração da cidade"*. |
| **robusto / robustez** | forte, confiável, estável, sólido | Use dados de carga e disponibilidade sempre que possível. |
| **holístico / visão holística** | completo, integrado, amplo, total | Descreva o que está incluso no escopo. |
| **sem atritos (seamless)** | suave, direto, fácil, sem atritos | Explique onde o atrito foi removido. |
| **game-changer** | decisivo, transformador | Mostre a métrica que justificou a mudança. |
| **o futuro parece promissor** | (Corte) | Diga qual é o próximo plano concreto ou não diga nada. |
| **apenas o tempo dirá** | (Corte) | Frase clichê para fugir de conclusões. |
| **no final do dia (at the end of the day)** | no fim das contas, afinal, em conclusão | Use com moderação ou corte. |
| **mindset** | mentalidade, postura, abordagem | Prefira termos nativos. |
| **pensar fora da caixa** | inovar, buscar outras soluções | Clichê corporativo gasto. |

## 3. Tier 2: Suspeitos em Cacho (Flag Quando Juntos no Mesmo Bloco)

Palavras que, isoladas, são corretas na língua portuguesa, mas quando aparecem duas ou mais no mesmo parágrafo formam a "textura plástica" típica de LLMs:

- **Lista de alerta:**
  - *fundamental*
  - *crucial*
  - *essencial*
  - *estratégico*
  - *relevante*
  - *sinergia*
  - *paradigma*
  - *empoderar*
  - *desbloquear (unlock)*
  - *potencializar*
  - *disruptivo*
  - *meticuloso*
  - *intricado*

- **Exemplo de Cacho (Flag):**
  > *"É **crucial** entender que essa abordagem **estratégica** cria uma **sinergia** que **potencializa** o valor da solução."*
- **Versão Corrigida:**
  > *"A integração entre os dois módulos reduz o retrabalho dos analistas."*

## 4. Tier 3: Densidade de Advérbios e Cacos de Transição

Palavras que enfraquecem a precisão técnica e devem ser podadas quando acumuladas:

| Advérbio / Caco | Quando Cortar | O que Fazer |
|---|---|---|
| **literalmente** | Quase sempre | Use apenas se o fato for estritamente literal (físico). |
| **simplesmente** | Na maioria das vezes | Ex.: *"Ele simplesmente parou"* ➔ *"Ele parou"*. |
| **realmente / verdadeiramente** | Quando servir de ênfase vazia | Deixe que o dado real transmita a certeza. |
| **fundamentalmente** | Quando for muleta de abertura | Corte e afirme a frase diretamente. |
| **inevitavelmente** | Em previsões incertas | Substitua pelo prazo ou risco real. |
| **muito / extremamente** | Sempre que puder ser medido | Troque por uma métrica (*"muito rápido"* ➔ *"em 5ms"*). |
| **na verdade / o fato é que** | Início de frases | Vá direto ao ponto sem o preâmbulo. |

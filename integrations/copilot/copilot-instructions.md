# Instruções de Redação em Português do Brasil para GitHub Copilot

Ao sugerir ou revisar textos, documentações em Markdown ou mensagens de commit em Português do Brasil:

1. **Clareza e Direção:** Use frases ativas e diretas (Ordem Sujeito + Verbo + Objeto).
2. **Sem Gerundismo:** Use verbos no presente ou futuro simples em vez de locuções como *"vou estar criando"*.
3. **Sem Formalismos Burocráticos:** Evite palavras como *"ademais"*, *"outrossim"*, *"destarte"*, *"cumpre salientar"*. Prefira *"além disso"*, *"por isso"* ou texto direto.
4. **Sem Emojis em Excesso:** Não coloque emojis decorativos em cabeçalhos Markdown (`# 🚀 Introdução`).
5. **Sem Falsa Dramaticidade:** Evite construções como *"Não é apenas X, é Y"* ou revelações teatrais com dois-pontos.
6. **Preservação de Código:** Nunca altere nomes de variáveis, imports, tabelas ou trechos de código em revisões de texto.
